# Asset attribution and distribution checklist

The mascot source images currently present in the repository were supplied during project development:

| Asset | Runtime version | Current status |
|-------|----------------|----------------|
| `face.webp` | `apps/tauri/public/avatars/face.png` | License not verified |
| `face2.jpeg` | `apps/tauri/public/avatars/face2.png` | License not verified |
| `face3.jpeg` | `apps/tauri/public/avatars/face3.png` | License not verified |
| `face4.jpg` | `apps/tauri/public/avatars/face4.png` | License not verified |

Before publishing Ichibot or distributing the DMG publicly, verify that the project has permission to redistribute each source image. Replace any image without a compatible license or add the required attribution and license terms here.

The transparent PNGs in `apps/tauri/public/avatars/` are generated derivatives used by the application; they inherit the licensing requirements of their source images.
